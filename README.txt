SCIENTIFIC CALCULATOR APP

Features:
- Login and Register account
- Account data and calculator history saved in browser localStorage
- Scientific functions
- DEG/RAD mode
- Light/Dark theme
- Calculation history
- Installable PWA

Run:
1. Unzip the project.
2. Open index.html in a browser.
3. For PWA Install and Service Worker, use a local/static web server (for example VS Code Live Server or GitHub Pages).

Important:
This version stores accounts locally in the browser. It is NOT a cloud multi-device authentication system.
